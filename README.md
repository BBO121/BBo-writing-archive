# 문장 보관소

BBo의 글을 모으고 공유하는 정적 사이트입니다. 설치나 빌드, 데이터베이스 없이 GitHub Pages에서 작동합니다.

## 글 올리기

VS Code에서 `posts.js`를 열어 `window.ARCHIVE_POSTS` 배열 안에 글을 추가합니다. 기존 글 한 덩어리를 복사해 수정하면 됩니다.

```js
{
  id: 'my-new-writing',
  title: '새 글 제목',
  date: '2026-11-03',
  category: '기록',
  excerpt: '목록에 표시할 한두 줄의 소개.',
  body: [
    '첫 번째 문단입니다.',
    '두 번째 문단입니다.\n문단 안에서 줄도 바꿀 수 있습니다.'
  ]
},
```

- `id`: 글마다 고유한 영문 소문자·숫자·하이픈으로 작성합니다. 공유한 뒤에는 바꾸지 않는 편이 좋습니다.
- `date`: `YYYY-MM-DD` 형식. 최신 날짜의 글부터 자동으로 정렬합니다.
- `body`: 문자열 하나가 한 문단입니다. HTML과 마크다운은 일반 글자로 표시합니다.
- 문자열에 작은따옴표를 넣으려면 `\'`, 역슬래시는 `\\`로 적습니다.
- 예시 글 3개는 본인 글로 교체하거나 삭제하세요. 배열을 비우면 빈 목록을 표시합니다.
- `posts.js` 안의 모든 글은 공개됩니다. 비공개 글과 개인정보는 넣지 마세요.

## GitHub Pages 연결

1. GitHub에서 `BBo-writing-archive`라는 빈 저장소를 만듭니다.
2. 이 폴더를 VS Code로 열고 소스 제어에서 커밋한 뒤 해당 저장소에 게시합니다.
3. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. **main**, **/(root)** 를 선택하고 저장합니다.
5. 배포가 끝나면 Pages 설정 화면에 나온 주소로 접속합니다.

이후에는 글을 수정하고 커밋·푸시하면 사이트에도 반영됩니다. 하위 경로에서도 동작하도록 모든 파일 경로는 상대 경로입니다. 글 주소의 `?post=...`를 포함한 전체 주소로 공유하세요.

사이트 제목과 소개는 `index.html`, 첫 화면 문구는 `app.js`, 색상은 `style.css` 맨 위에서 수정합니다.

## 미리보기

`index.html`을 브라우저로 열거나 VS Code의 Live Server로 엽니다. 주소 복사는 HTTPS 또는 localhost에서 작동하며, 사용할 수 없는 환경에서는 주소창 복사를 안내합니다.

## 백업

커밋하고 GitHub에 푸시한 글은 저장소와 수정 기록에 남습니다. 중요한 원고는 별도 위치에도 복사해두면 좋습니다.

이 사이트는 브라우저에서 글을 표시합니다. 공유 주소로 글을 바로 열 수 있지만, 서비스별 링크 미리보기는 공통 사이트 제목을 표시할 수 있습니다.
